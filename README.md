# FitCut (가칭)

사진·영상·음성을 내 기기에 딱 맞게. 폰 배경화면, 워치 페이스, 움짤, 벨소리, 방송 하이라이트를 한 곳에서 만드는 웹 서비스.

> 상태: M0(프로젝트 기반) 진행 중. 설계 문서는 [docs/](docs/)에 있다.

## 만든 이유

사진 리사이즈 사이트를 써보면 불편한 점이 많았다.

- 기기별 배경화면 크기를 직접 찾아서 숫자로 입력해야 한다.
- 원형 워치 화면에 맞춘 크롭이 없다.
- 광고와 옵션이 많아 화면이 복잡하다.
- 사진을 서버에 올려야 하고, 기다려야 한다.
- 움짤이나 음성 추출은 사이트를 따로 찾아야 하고, 구간을 세밀하게 고르기 어렵다.

## 주요 기능

| 도구 | 하는 일 |
| --- | --- |
| 사진 | 리사이즈·크롭, 아이폰·갤럭시·폴드·플립·아이패드·갤럭시 탭·애플워치·갤럭시 워치 프리셋, 여러 기기 한 번에 내보내기 |
| 움짤 | 프레임 단위 구간 선택, GIF·WebP·MP4, 워치용·움짤용 크기 |
| 음성 | 영상에서 음성 추출, 구간 자르기, 페이드, 음량 맞추기, 벨소리 프리셋 |
| 링크 구간 | 유튜브 링크를 공식 플레이어로 재생하며 구간 저장·반복 재생 |
| 하이라이트 | 스트리머가 채널을 연결하면 라이브 채팅으로 하이라이트 후보를 찾고, 녹화 파일에서 바로 클립·움짤로 |
| 관리자 | 관리자만 보는 사용 분석, 비용, 보관 동의 파일 |

## 아키텍처 핵심

- 사진 작업은 브라우저에서 처리한다. 서버 비용 0, 사진이 기기 밖으로 나가지 않는다.
- 무거운 영상 작업만 서버리스 파이프라인에서 처리한다. 작업 크기에 따라 Lambda와 Fargate Spot을 나눠 쓴다.
- 라이브 채팅 수집기는 방송 중에만 돈다. 웹훅을 주는 플랫폼은 Lambda만으로 받는다.
- 사용 이벤트는 Data Firehose → S3 → Athena로 쌓아 관리자 화면에서 분석한다. 파일 내용 대신 메타데이터만 수집한다.
- 상시 켜진 서버가 없어서 사용자가 없을 때 비용이 거의 0이다.

자세한 구성: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
