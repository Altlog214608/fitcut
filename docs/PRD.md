# PRD: FitCut (가칭)

## 1. 문제

### 일반 사용자

기존 사진 리사이즈 사이트를 쓰며 겪은 불편:

- 기기별 배경화면 크기를 직접 검색해서 숫자로 입력해야 한다.
- 워치처럼 원형·둥근 화면에 맞춘 크롭이 없다.
- 광고와 옵션이 많아 화면이 복잡하다.
- 사진을 서버에 올려야 해서 기다려야 하고, 찜찜하다.
- 영상을 움짤로 바꾸거나 음성만 뽑으려면 사이트를 따로 찾아야 하고, 구간을 세밀하게 고르기 어렵다.

### 스트리머·클립 편집자

몇 시간짜리 방송에서 하이라이트를 찾으려면 영상을 처음부터 다시 봐야 한다.

### 오디오 크리에이터

오디오 방송(스푼 등)이나 녹음 파일에서 일부만 잘라 공유하기 번거롭다.

## 2. 대상 사용자

| 사용자 | 상황 | 핵심 요구 |
| --- | --- | --- |
| 일반 사용자 | 폰·워치 배경화면, 움짤, 벨소리를 만들고 싶다. 주로 폰에서 접속 | 빠르고, 기기 크기를 몰라도 되고, 화면이 단순할 것 |
| 스트리머·클립 편집자 | 방송에서 하이라이트를 뽑고 싶다. 주로 PC에서 접속 | 채널을 연결해두면 하이라이트 위치를 알려주고, 녹화 파일에서 바로 클립을 만들 것 |
| 오디오 크리에이터 | 녹음 파일에서 일부를 잘라 공유하고 싶다 | 음성 구간 자르기, 공유용 영상 만들기 |
| 관리자 (본인) | 서비스가 어떻게 쓰이는지 알고 싶다 | 사용 분석, 비용, 보관 동의 파일 확인 |

## 4. 하지 않는 것

- 외부 URL에서 영상·음성 내려받기 (일부 구간 포함), 방송 녹화
- 링크로 넣은 영상을 GIF나 파일로 바꾸기 (링크는 재생과 구간 저장만)
- 비공식 API 사용, 공식 API가 없는 플랫폼 연동 (SOOP, 스푼 등)
- 사용자가 채팅 로그 파일을 직접 올리는 기능
- 방송 송출 서비스
- 필수 회원가입 (일반 기능은 로그인 없이 쓴다. 하이라이트는 채널 연결이 필요하다)
- 동의 없는 사용자 파일 장기 보관, 공개 갤러리
- 본격적인 영상 편집 (자막 편집, 효과, 여러 클립 합치기)
- 광고, 워터마크

## 5. 성공 지표

사용자 경험:

- 사진 하나로 첫 배경화면을 얻기까지 30초 이내 (모바일 기준)
- 움짤·음성 만들기에서 구간 선택부터 저장까지 막힘 없이 진행 (사용자 테스트 5명)

포트폴리오 (README 측정 결과 표에 기록):

- 월 운영 비용 (실제 청구액), 그중 분석 파이프라인 비용
- 사진 작업당 서버 비용 (목표 0)
- GIF 잡의 p95 처리 시간과 잡당 비용
- 3시간 방송 1회 채팅 수집·분석 비용
- 하이라이트 후보 정확도 (직접 표시한 구간 대비 precision@10)
- 실사용 스트리머 수

## 6. 원칙

- 처리 대상은 사용자가 권리를 가진 파일이라는 전제다. 업로드 화면에 이를 안내한다.
- 외부 플랫폼은 공식 API와 약관을 따른다.
- 업로드·결과 파일은 기본적으로 자동 삭제한다 (보통 1~2일 안에). 장기 보관은 동의한 경우에만 30일.
- 분석은 파일 내용 없이 메타데이터로 한다. 파일명, 원본 IP, 채팅 닉네임은 저장하지 않는다.
- 스마트 크롭은 얼굴 위치만 쓰고 얼굴 데이터를 저장하지 않는다.
- 공개 전에 개인정보 처리방침과 동의 문구를 법적으로 검토한다.
